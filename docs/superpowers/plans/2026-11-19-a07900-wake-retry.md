# Retry Automatico Protetto con Sveglia su `A07900` — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aggiungere a `LepasCoordinator.async_send_command` un retry automatico protetto (massimo 1 volta) su `CommandError(code="A07900")`, preceduto da rilascio di `_cmd_gate`, sveglia `localizza` condivisa (`async_assicura_sveglia`) e attesa reattiva dell'evento MQTT paho→asyncio (`_wait_for_car_wake`), con cooldown di 60 s e ripristino dello stato originale su fallimento.

**Architecture:** Una nuova costante `A07900_WAKE_COOLDOWN_S = 60` in `const.py` regola il rate-limit delle sveglie automatiche su `A07900`. In `LepasCoordinator`, `_on_car_message` (thread paho) segnala `self._mqtt_msg_event` al loop asyncio tramite `call_soon_threadsafe` dopo l'aggiornamento atomico di `self._last_msg_ts`; `_wait_for_car_wake` esegue un double-check sotto `self._state_lock` attorno a `_mqtt_msg_event.clear()` per eliminare qualsiasi race condition. Quando `async_send_command` riceve `A07900` idoneo, il `finally` del primo tentativo rilascia `_cmd_gate` prima di `async_assicura_sveglia()`, quindi attende `_wait_for_car_wake` e riprova esattamente una volta con `_allow_wake_retry=False` (riusando il `taskId` in cache) oppure ripristina `cmd_status`, instrada il rimedio e rilancia l'errore originale.

**Tech Stack:** Python >=3.12, Home Assistant `DataUpdateCoordinator`, `asyncio` (`Event`, `Lock`, `wait_for`), `threading.Lock`, `paho-mqtt`, `pytest` + `pytest-homeassistant-custom-component`, `uv`, `ruff`.

### `StateGraph` (`onSuccess:` / `onFailure:` & `try...finally` guarantees)
1. **Tentativo 1 in `async_send_command`**:
   - Acquisizione `await asyncio.wait_for(self._cmd_gate.acquire(), timeout=COMMAND_QUEUE_WAIT)`:
     - `onFailure (TimeoutError)`: solleva `HomeAssistantError` senza entrare nel `try...finally`.
   - Dentro `try ... finally`:
     - `onSuccess`: `consegnato = True` → schedula `_hold_then_release()` (che rilascia `_cmd_gate` nel proprio `finally` dopo `_settle_after_command()`).
     - `onFailure (A07900 idoneo)`: salva `wake_err`, `err_cmd_status`, `err_note_cmd`, `err_note_cmd_at`; NON chiama `_diag.record`/`_instrada_rimedio` e NON rilancia ancora; esce dal `try` → `finally` rilascia `self._cmd_gate.release()` (`consegnato == False`).
     - `onFailure (altro errore o A07900 non idoneo)`: registra `_diag.record(ok=False)`, chiama `_instrada_rimedio(err)`, rilancia `err`; `finally` rilascia `self._cmd_gate.release()`.
     - `onFailure (CancelledError)`: `finally` rilascia `self._cmd_gate.release()`, `CancelledError` si propaga.
2. **Fase Sveglia & Attesa MQTT (fuori dal `try...finally`, con `_cmd_gate` LIBERO)**:
   - Imposta `self._last_a07900_wake_ts = time.monotonic()` e legge `baseline_ts = self._last_msg_ts` sotto `self._state_lock`.
   - `await self.async_assicura_sveglia()` → acquisisce `_cmd_gate` per `"localizza"`, poi lo rilascia (via `_hold_then_release`).
     - `onFailure (CancelledError)`: `_cmd_gate` dell'invocazione esterna è già libero; `shield` in `async_assicura_sveglia` protegge il task condiviso.
   - `await self._wait_for_car_wake(baseline_ts, timeout=POLL_WAKE_WAIT)`:
     - `onSuccess (True)`: invoca `return await self.async_send_command(key, params, _allow_wake_retry=False)` (ri-acquisisce `_cmd_gate` in modo pulito, riusa `taskId` in cache).
     - `onFailure (False: timeout o _timers.closing)`: registra `_diag.record(ok=False)`, ripristina `self._note_cmd`, `self._note_cmd_at` e `self._apply_update({"cmd_status": err_cmd_status})`, chiama `self._instrada_rimedio(wake_err)`, e rilancia `wake_err`.

async def test_a07900_cancelled_error_durante_attesa_lascia_cmd_gate_libero(

    coord = _coordinator(hass, integrazione_avviata)
    coord._last_msg_ts = 0.0

    monkeypatch.setattr(coord_mod, "POLL_WAKE_WAIT", 5.0)

        ),

    assert tentativi == {"blocca": 1, "localizza": 1}

    async def _wait_for_car_wake(
        self, baseline_ts: float, timeout: float = POLL_WAKE_WAIT
    ) -> bool:
        """Attende fino a `timeout` s che arrivi un push MQTT successivo a `baseline_ts`."""
        deadline = time.monotonic() + max(0.0, timeout)
        while True:
            if self._timers.closing:
                return False
            with self._state_lock:
                if self._last_msg_ts > baseline_ts:
                    return True
            self._mqtt_msg_event.clear()
            with self._state_lock:
                if self._last_msg_ts > baseline_ts:
                    return True
            if self._timers.closing:
                return False
            remaining = deadline - time.monotonic()
            if remaining <= 0:
                return False
            try:
                await asyncio.wait_for(self._mqtt_msg_event.wait(), timeout=remaining)
            except asyncio.TimeoutError:
                with self._state_lock:
                    return (not self._timers.closing) and (self._last_msg_ts > baseline_ts)

    def _should_wake_retry_on_a07900(
        self, key: str, err: Exception, allow_wake_retry: bool
